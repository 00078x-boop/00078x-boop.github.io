Política de Privacidade — Vice City Baby Postador

Última atualização: 18 de novembro de 2026.

O "Vice City Baby Postador" é uma ferramenta pessoal, usada somente pelo dono do canal do YouTube Vice City Baby (@vcitybaby), para enviar e agendar os próprios vídeos no canal.

Dados acessados

Com a autorização do dono da conta, a ferramenta usa a API do YouTube para enviar vídeos, ler e editar informações dos vídeos do próprio canal e ler estatísticas do canal. Nenhum dado de outros usuários é coletado.

Armazenamento e compartilhamento

As credenciais de acesso ficam guardadas apenas no computador do dono do canal. Nenhum dado é vendido, compartilhado com terceiros ou enviado para outros servidores além da própria API do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
